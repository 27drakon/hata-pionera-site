Как работает приложение

Создано для своего канала

Hata Pionera («Хата Пионера») — локальное приложение для подготовки, планирования и контроля публикаций игровых видеосерий, в том числе на YouTube-канале KG_PIONER_PLAY.

Видео и рабочие файлы обрабатываются на компьютере пользователя; данные для загрузки отправляются на YouTube через официальный API только при включении соответствующих функций.

🔐 Доступ только с разрешения владельцаДля работы с YouTube приложение запрашивает разрешение владельца канала через Google OAuth. С его разрешения приложение может проверять сведения о канале и видео, загружать видео и настраивать публикацию по расписанию. Пароль Google приложению не передаётся.
