«Хата Пионера» — локальная программа для работы с игровыми видеосериями. Она помогает выстроить путь от подготовленного видео до запланированной публикации.

🎬

Подготовка серий

Очередь видео, файлы, контроль обработки и готовности к публикации.

🗓️

Планирование

Описание, метаданные и время выхода: всё собрано в одном рабочем процессе.

🛡️

Контроль без дублей

Проверки авторизации и существующих публикаций перед автоматическими действиями.

Немного о технической стороне

Приложение работает на компьютере владельца канала

Для функций YouTube используется официальный Google OAuth и YouTube Data API с разрешения владельца канала. Пароль Google приложению не передаётся. Обработка видео и рабочей очереди происходит локально; отправка видео на YouTube предусмотрена только при включении функции публикации.

Подключение YouTube API настроено. Механизм полной автоматической загрузки находится в разработке.
