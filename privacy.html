Политика конфиденциальности Hata Pionera

Обновлено: 12 ноября 2026 г.

Назначение и доступ

Hata Pionera — программа для локального управления видеопубликациями. Для доступа к YouTube используется Google OAuth с разрешения владельца канала. Программа может читать идентификатор канала и сведения о видео, а после отдельного включения функций — загружать видео и управлять временем их публикации.

Хранение и использование данных

Настройки очереди, технические журналы и токены OAuth хранятся локально на устройстве пользователя. Токены используются для обращения к YouTube Data API и обновления доступа. Видео и связанные метаданные передаются Google/YouTube, только когда пользователь включает и запускает соответствующие функции публикации.

Передача данных

Приложение не продаёт данные Google-пользователя и не передаёт их рекламным посредникам. Данные, нужные для работы с каналом, отправляются в Google API в рамках предоставленных разрешений.

Управление доступом и удаление

Владелец может отозвать доступ в настройках безопасности Google-аккаунта («Сторонние приложения и сервисы»). Локальные токены и рабочие данные можно удалить с устройства. Отзыв доступа прекращает дальнейший доступ приложения к YouTube до новой авторизации.

Контакты

По вопросам доступа и обработки данных обращайтесь к владельцу приложения через контактный адрес, указанный на экране согласия OAuth.
